## Resume material priorities

Select the strongest relevant current material across existing resumes, tailored cuts, portfolio evidence, and project work. A file named canonical is not automatically the best starting point.

- **Lead employer:** _(optional; an employer that always leads Experience, regardless of reverse chronological ordering)_
- **Other core employers:** _(preserve their substantial ownership and impact; adjust bullet emphasis and space for the posting instead of replacing strong employment evidence with minor projects)_
- **Priority projects:** _(choose the strongest relevant subset for the job and page budget; this is a preference for major work, not a requirement to include every project in every resume)_
- **Projects not to reintroduce:** _(older or minor projects that should not return just because they match a framework in the posting; do not carry their keywords into a new cut to pad its Skills section)_

A project's absence from one old cut does not exclude it from future tailored cuts. Reassess relevance using these priorities.

## Rules for every profile

For phone number and address, use the current resume or an established application profile, and resolve any actual conflict before submission. Do not freeze an old address into a reusable skill.

When the portal lacks the ethnicity answer given above, do not silently replace it with another option. Use an explicit portal definition only if it unambiguously includes that answer. Otherwise retain Decline to State where available, flag the mismatch in the review, and ask only if a required unanswered field blocks progress.

If no veteran-status answer is supplied, do not infer military history from citizenship or disability. Retain an established decline response or ask if a factual answer is required.

Private or collaborative projects may appear in tailored experience when supported by the owner's contributions, but do not link a private repository in the resume, application, or review gallery. Each private project follows its own verified sharing permissions.

Citizenship and work authorization in one country do not answer work eligibility for another country, export-control status, security clearance, or every immigration question. Read the actual question.
