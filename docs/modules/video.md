# Creative and video workflows

Choose this for launch videos, deterministic animation, compositions and rendering. The repo retains brag and all six HyperFrames-related skill entries, with references/assets and vendor hashes. Select individual skills if you prefer; choosing this module brings its complete bundled set.

Install the runtime dependencies described in the selected skills, then build a small composition and run its documented checks before rendering a full video. Cloud renders, narration, media providers and publication need your own service access and separate authorization. Copying a skill does not install FFmpeg, Node, Blender or a cloud account.

The vendor sources stay at `vendor/skills/` and the lock verifies their content. Public upstream notices and font licenses remain with their files. Source media is retained from the existing shared repo; read the included media attribution/terms before reusing it outside the sample workflow. The bank's companion license files come from the sanitized starter pack.

For the full current upstream collection rather than this pinned snapshot, use the maintainers' installation guides and choose your destination deliberately: [HyperFrames](https://github.com/heygen-com/hyperframes), [brag](https://github.com/latent-spaces/brag). Provider-owned skills remain separate.
