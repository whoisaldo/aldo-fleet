# Legacy and deprecated reference bank

Keep this if you want the previous machine migration, multi-account profiles, retired installer examples and cache measurement methods. Skip it for a fresh minimal setup.

`imports/`, `examples/legacy-fleet.json` and the legacy docs preserve earlier source. Historical scripts are not run by the bank or ordinary bootstrap. They may assume hostnames, D: drive layouts, subscriptions, scheduled tasks or ports you do not have.

Keep reusable older skills when they match your task. The image/3D/browser bridges retain their examples and standalone helpers. The current OpenClaw visual recipe distinguishes old canvas behavior from the newer widget/dashboard guide. Treat dated verification as evidence of that original installation, not a check of your machine.

Do not replay recovery commands, account rotation or provider migration against a live installation merely because they appear in a legacy file. Use the selected current recipe and the actual installed version.
