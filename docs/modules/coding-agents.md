# Coding agents

Choose this if you want agents working in your repositories. You can use Codex, Claude Code or both without a proxy, OpenClaw or T3. Use your own subscription or approved work access.

Install from the provider's current guide. For Codex, the official CLI guide documents installation and first-run sign-in. Claude Code has its own setup guide. Open a disposable project and verify a file read before using a real task.

Keep personal and work homes separate. A skill is instructions and helper files; installing it does not grant model access, connectors, calendar permissions or computer control. Preserve the specialized model/effort requirements in any bridge you select.

The repo's optional pinned CLI installers reproduce the source toolchain without replacing global CLIs. They are compatibility snapshots, not the latest release. Use the fleet-tools module only if you want that deployment model.

Sources checked October 14, 2026: [Codex CLI](https://learn.chatgpt.com/docs/codex/cli), [Claude Code setup](https://code.claude.com/docs/en/setup).
