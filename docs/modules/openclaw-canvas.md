# OpenClaw visual canvas and widgets

Choose this for visual documents, widgets and dashboards alongside the assistant. This is different from the school Canvas LMS module, which reads coursework.

Install/onboard OpenClaw first. Check your installed version's visual features before following an old canvas tutorial. Current documentation at the historical macOS canvas URL describes a widget panel; A2UI widgets belong on session dashboards, and the macOS panel does not accept the old A2UI push/reset workflow. Older instances can still have canvas documents or retired root settings.

Use the current [widget panel guide](https://docs.openclaw.ai/platforms/mac/canvas) and [session dashboards](https://docs.openclaw.ai/web/dashboards) for your version. Confirm the companion/node is paired, render a harmless local document or widget, and verify its visible result before attaching personal data or interaction permissions.

For an older canvas installation, inspect the documented migration and back up its private document root first. Treat `doctor --fix` as a migration that changes state, not a harmless installation check. Do not copy the source owner's canvas directory or overwrite existing documents. The bank does not apply migrations or pair devices.

When sharing something with a friend, export or serve the intended document/app view through the preview recipe. Do not assume that sharing the assistant's control UI is equivalent to sharing that document.

Sources checked October 14, 2026: the official widget panel and dashboard guides linked above. Old canvas commands remain version-specific reference material.
