# OpenClaw

Choose this for a persistent assistant with browser work, schedules and optional messaging channels. It is independent of T3 Code and CLIProxyAPI. Skip it for ordinary coding sessions.

Start with [OpenClaw's setup guide](https://docs.openclaw.ai/start/getting-started). Install the official distribution, complete onboarding with your own model account, and check the configured Gateway with `openclaw gateway status`. Open the Control UI with `openclaw dashboard`, then verify a short reply. The default documented Gateway port is 18789. Review service installation separately if you want it to run in the background.

Keep initial access local. Add a channel, browser profile or private remote route only when you need it. Existing installations should be inspected and merged carefully rather than replaced with the original owner's entire configuration.

The optional Canvas LMS module outlines planning and organization capabilities through your own supported integration. Visual canvas/widgets are a separate module. Channels, memory and glasses are in assistant-extras.

Use `openclaw skills list` and `openclaw skills check` to discover what your installation can load. The selected skill folders include scripts/references and need their documented tools. See [skill locations](../install-skills.md) before copying them.

The catalog under provider-skills is a general capability reference. It contains no record of the source owner's enabled tools. Do not copy private workspaces, browser cookies, session stores, device grants or refresh credentials from somebody else's OpenClaw.

Sources checked October 14, 2026: [getting started](https://docs.openclaw.ai/start/getting-started), [skills](https://docs.openclaw.ai/tools/skills).
