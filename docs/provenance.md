# Sources and verification

This public bank combines portable fleet source, vendored creative skills and general assistant capability guides. Private configuration, memory, school records, browser state, tokens, device keys, account inventories and personal schedules are excluded.

The optional assistant skills are general Canvas planning, shared-resource review and form-requirements review. Canvas access depends on the reader's own supported integration.

The base fleet retains useful legacy bridge scripts, explicit model requirements and vendored creative assets. `skills/external.lock.json` pins vendored content. Upstream notices and font licenses stay with their files; companion notices are in bank/licenses. Historical hashes in imports/source-manifest.json describe source captured before public adaptation.

Recipes link to official upstream documentation checked October 14, 2026. Provider built-ins, synced organization tools, plugins and separate wearable applications remain with their providers. The OpenClaw catalog is a general capability reference, not a record of the owner's enabled tools.

The selector's bank/files.json contains SHA256 hashes for staged source. Updating source requires a reviewed index refresh. Untracked or ignored local configuration is excluded. A bundle manifest records the selected exported bytes; selection.json records modules, skills and external setup needs.

Offline tests cover selection dependencies, selective export, preservation of existing outputs, hash mismatch rejection, ignored-file exclusion, subset releases and deployment protections. Privacy checks cover current tracked source and reachable Git history. These checks do not establish live account access, institution permissions, friend access, device pairing or native Windows display behavior. Verify selected integrations in your own environment.
