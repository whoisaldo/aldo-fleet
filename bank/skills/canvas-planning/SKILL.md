# Canvas planning

Help the user choose which Canvas LMS capabilities would be useful: reviewing schedules and due dates, summarizing announcements, organizing learning materials, or connecting relevant dates to their preferred calendar or task system.

Start with a capability overview. Live access depends on the user's own authorized account and the tools available in their environment. Explain which options need an integration rather than implying the bank already connects to Canvas.

When live planning is requested and supported, use only the selected account and requested scope. Keep course names, identifiers, records, browser state and personalized planning data private. A planning request does not authorize completing or submitting coursework. Preserve existing notes and tasks when an authorized calendar or agenda integration is used.
