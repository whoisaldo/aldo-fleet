# Shared resource review

Review the document or resource collection the user provides. Include relevant linked and embedded content when accessible; a landing page's resource labels are not the full document.

Use the browser's observed document or frame controls to read the material. Report inaccessible or unread sections rather than implying full coverage. Keep sign-in destinations separate from reviewed content.

Distinguish explicit requirements from recommendations. Cite the relevant source for each requirement, identify conflicts and missing information, and produce a concise checklist when useful. Reviewing material does not authorize changing a form, publishing a linked artifact or submitting anything.
