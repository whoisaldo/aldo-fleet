# Example Mac worker

Configure the Mac's user, checkout, SSH alias and address in fleet.json. It handles macOS, iOS, browser and Blender work. A headless worker's GUI is not visible to its remote operator; give verified preview URLs and saved screenshot paths.

Bind previews to a configured trusted network only when remote access is needed. Confirm the actual address rather than assuming a placeholder is reachable. Preserve the current T3 app, provider settings, services and database. Never launch another backend against a live T3 home or change existing Tailscale Serve during ordinary work.

Choose the account when the thread starts. Keep work and personal repositories, memory, artifacts and sign-ins separate. Check existing workload before starting a heavy build. Recovery details, hardware inventory and account records belong in private machine notes.
