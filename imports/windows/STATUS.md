# Validation template

Record your own results in private state: OS/toolchain versions, ordinary-user file access, fresh agent execution and follow-up, T3 reachability, and interactive GPU/display evidence. A historical script's presence does not establish that any check passed on your worker.

Keep account details, hardware inventory, host fingerprints, session IDs and raw logs outside the public repository. See [Windows deployment](../../docs/windows-deployment.md).
